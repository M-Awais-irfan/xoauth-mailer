# Security Policy

## Supported versions

Security fixes are released for the latest version only.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report it privately through GitHub instead: open the **Security** tab of this repository and choose **Report a vulnerability**.

Include the plugin version, WordPress version, steps to reproduce and the impact you see. You will get a reply within 7 days, and a fix will be released as soon as it is ready. Reporters are credited in the changelog unless they prefer not to be.
